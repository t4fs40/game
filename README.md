## 🌌 О проекте

**Elden Ring Fan Site** — это некоммерческий фанатский проект, посвящённый эпическому фэнтези-миру Lands Between из игры Elden Ring от FromSoftware. Сайт создан для истинных Потусторонников, стремящихся разгадать тайны Великой Воли.

## ⚔️ Функционал и разделы

- **📜 Хроники Междуземья** - полный анализ сюжета, персонажей и фракций
- **🗡️ Энциклопедия вооружения** - всё о легендарном оружии, заклинаниях и навыках
- **🗺️ Интерактивные карты** - детализированные карты всех регионов с секретами
- **🏆 Галерея достижений** - скриншоты и арты из мира Элдена Риг
- **📱 Адаптивный дизайн** - корректное отображение на всех устройствах

## 🛠️ Технологии

  Frontend:
├── HTML5
├── CSS3 (Flexbox/Grid)
├── JavaScript (ES6+)
├── Leaflet.js (интерактивные карты)
└── Swiper.js (галереи изображений)
